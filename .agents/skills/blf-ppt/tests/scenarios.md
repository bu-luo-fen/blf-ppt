# 行为验收场景

这些是后续在真实 Codex 任务中执行的人工用例；本次打包未假称已模拟完整 Agent 行为。

| 场景 | 输入要点 | 期望观察 |
| --- | --- | --- |
| 仅有主题 | “帮我做量子传感组会 PPT” | 从受众与目标着手给出可修订故事线；不强迫提交完整大纲；只问影响方向的问题。 |
| 论文与参考 PPT | 提供论文、参考稿并要求汇报 | 实际分析参考稿的多种页面类型；区分论文成果与用户项目成果；真实图表保留来源。 |
| 指定路线 A | 已明确要求当前 Codex 生图 | 不重复询问路线；检查可用工具并调用真实生图能力；检查图中文字与关系。 |
| 指定路线 B | 已明确要求独立 ChatGPT 窗口生图 | 不自行改用 A；给出完整可复制的图片任务说明和返回清单，收到文件后再组装。 |
| 检查或修复旧 PPT | 提供 PPTX 并要求修复 | 先检查已有内容与结构，双遍视觉检查；修复后说明实际验证、遗留问题与状态。 |
| 普通论文问答 | “这篇论文的贡献是什么？” | 不触发本 Skill 的 PPT 制作流程，不询问生图路线。 |

各制作场景还需核对：规划后才决定生图路线；关键科学事实有依据；PPTX 可打开、页数与计划一致、严重问题已处理；无法执行的视觉检查明确说明。
